# Draftlab design

Working surface for coaches during practice. Dark ink surfaces reduce glare beside the game client; warm chartreuse highlights the current decision, blue and coral identify sides. A compact rail, draft board, champion library and explanatory recommendation column form the desktop composition. On mobile these become a horizontal navigation and stacked sections. Outfit headings and Inter body, real champion portraits, restrained borders, no decorative hero. All status colors have text labels. Visible keyboard focus and reduced-motion support.
